# Task 2 – House Price Prediction

## 📌 Project Overview

This project focuses on predicting house prices using machine learning techniques. The dataset contains various features related to properties, which are used to train models and predict house prices.

## 🎯 Objective

The main objective is to build a machine learning model that can predict house prices based on different property-related features.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Steps Performed

1. Loaded and inspected the dataset
2. Checked the structure and data types
3. Handled missing values
4. Performed exploratory data analysis
5. Selected relevant features
6. Split the dataset into training and testing sets
7. Trained machine learning models
8. Evaluated model performance
9. Compared predicted values with actual house prices
10. Visualized the results

## 🤖 Machine Learning

The project uses regression-based machine learning techniques to predict house prices.

## 📊 Evaluation

Model performance was evaluated using appropriate regression metrics such as:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## 💡 Key Outcome

The trained model is able to estimate house prices based on the features provided in the dataset. The analysis also helps understand which property characteristics influence house prices.

## 📁 Files

- `house_price_prediction.ipynb` – Jupyter Notebook containing the complete analysis and model
- `dataset.csv` – Dataset used for the project
