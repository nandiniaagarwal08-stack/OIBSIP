# Task 3 – Wine Quality Prediction

## 📌 Project Overview

This project focuses on predicting wine quality using machine learning classification techniques. The model uses physicochemical properties of wine to predict its quality score.

## 🎯 Objective

The main objective is to build and compare multiple machine learning classification models to predict wine quality based on features such as acidity, density, alcohol content, and other physicochemical properties.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Steps Performed

1. Loaded and inspected the Wine Quality dataset
2. Checked dataset structure and data types
3. Analyzed the distribution of wine quality scores
4. Checked and handled missing values
5. Performed exploratory data analysis
6. Selected features and target variable
7. Split the dataset into training and testing sets
8. Applied feature scaling where required
9. Trained multiple classification models
10. Compared model performance
11. Evaluated predictions using classification metrics

## 🤖 Machine Learning Models

The following classification models were used and compared:

- Random Forest Classifier
- SGD Classifier
- Support Vector Classifier (SVC)

## 📊 Evaluation Metrics

Model performance was evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 💡 Key Outcome

The project demonstrates how machine learning classification algorithms can be used to predict wine quality based on its physicochemical properties and compare the performance of different models.

## 📁 Files

- `wine_quality_prediction.ipynb` – Jupyter Notebook containing the complete analysis and machine learning models
- `winequality.csv` – Dataset used for the project
